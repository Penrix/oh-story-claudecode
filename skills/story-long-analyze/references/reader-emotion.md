# 读者情绪提炼

> 拆黄金三章、逐章摘要与 Stage 3 情绪模块时使用。先按原文记录事实，再判断这些事实怎样让读者产生感觉。不得用情节概要代替情绪分析。

## 1. 先分清三个问题

1. **情绪质地：这是什么感觉？** 用具体中文说清读者得到的感觉，如得意、风流、温暖、昂扬、自由、豪迈、憋屈、神秘。不要只写“很爽”“很有情绪价值”。
2. **情绪指向：为什么会有这种感觉？** 说明哪些已经成立的人物能力、关系、身份、信息差、社会评价和行为使读者产生这种感觉。例如“得意”可能来自主角有真本事而旁人尚未识货，也可能来自成名以后从容享受高价生活。
3. **情绪时间形状：感觉怎样沿阅读时间变化？** 回看前面已经发生、读者已经知道和期待的事，写出这一段感觉如何出现、积累、变化、兑现、回返或持续。形状按原文实际阅读效果写，不套固定五步。

**故事运动另外记。** “筹钱→进武馆→拜师→参加武考→取得官身”是事件和身份变化；“不甘→希望→得意→期待渐强→扬眉吐气→享受成果”才是相应的情绪变化。不能把前一条当后一条。

情绪质地是要提炼的感觉；情绪指向用来解释这种感觉的来由；情绪时间形状用来说明它怎样在阅读中发生。三项不是三个互不相干的分类。

## 2. 拆单章时怎样做

按以下顺序操作：

1. **先白描事实。** 保留本章人物做了什么、结果如何、关系与状态怎样改变。原文没有给出的动机不猜。
2. **找读者当时的处境。** 读者此前已经知道什么、等着看什么、对人物形成了什么印象？没有前文证据时只分析本章，不虚构长线期待。
3. **说出实际感觉。** 用一两个准确的情绪词或一句具体描述回答“读到这里是什么感觉”。一章有多种感觉可以并列，有主次就标清主次。
4. **解释产生条件。** 指出是哪一句话、哪个行动、哪个对照、哪段关系历史或哪个信息披露使感觉成立。尽量指向情节点或原文位置。
5. **写出变化。** 回看本章前后的感受有什么不同；如果这一段只是持续温暖、享乐、幽默或自由，也如实写“持续”，不要编造缺口、危机或爆发。

逐章摘要保留原有 `关键信息与扩写技法`、`情绪流向` 和情节点格式；把上述判断填入已有字段，不另造与程序冲突的文件或标签。情节点后的 `基调：` 枚举仍按原格式填写，它只是检索标签，不代表完整情绪提炼。

## 3. Stage 3 怎样从章节提炼全书情绪

1. 按章节顺序连读已落盘的事实、情绪流向、人物与关系变化。
2. 找到能连续消费的一段感觉：从哪里开始，靠什么持续，到哪里转向或兑现；可以跨章，也可以在一章里同时存在几种感觉。
3. 记录相同感觉在不同剧情单元怎样再次出现、有什么变化。明确长期主要在提供什么感觉，哪些只是局部调味。
4. 把具体人名、地名、事件名、金手指、圈层名称暂时拿掉，写一遍只剩 Reader 感觉的变化。再对照原文检查是否仍然准确。这是“无歌词回听”，不是让你删掉事实证据。
5. 在 `剧情/情绪模块.md` 中，先写情绪质地和情绪指向，再写真实情绪链，最后才提炼能复用的戏剧做法和角色作用。保留原有 EM 字段名，按输出模板填写。
6. 在 `剧情/节奏.md` 中说明情绪沿阅读时间的变化；爽点循环、爆发点和高潮密度只记录原书确实存在的部分，不强加给日常、温暖和享乐段落。

不得凭书名、题材或开头三章判定整本书的主导情绪；资料只覆盖前几章时，结论只写到所读范围。

## 4. 可以怎样迁移

先保留“读者获得什么感觉、为什么获得、怎样逐步获得”，再去新书寻找能够产生同类感觉的人物和事实。

例如原书靠“低位者取得官身”让读者从不甘走到扬眉吐气，新书可以通过事业成功、作品成名或进入高价圈层产生相近体验；不能只把武考改名为商业竞赛，就算完成迁移。

保留原有 `读者想看什么`、`情绪链`、`戏剧单元`、`可替换项`、`不可照搬` 五个 EM 必填字段。新增解释不得删改这些字段名。

## 5. 完成前自查

- 是否明确写出了读者得到的感觉，而不只是事件、结果、需求或套路名？
- “为什么有这种感觉”是否能指向本书真实人物、关系、信息与行动？
- 情绪变化是否按真实阅读顺序恢复，而不是统一写成“缺口→加压→爆发”？
- 有没有把角色自己的情绪误当成读者的感受？
- 用于复现的戏剧单元是否与情绪分开，且没有照搬原文具体桥段？
- 是否把尚未阅读到的全书体验写成了确定结论？

以上任一项没有做到，回到有关章节与现有产物补足；证据不足就限定范围，不编造。
