# 长篇章节质量检查清单

> 谁读：主会话写完一章、排查具体问题时读，不预读。

只查写好的这一章。维度与 workflow-chapter「质量检查」一致：情绪交付、钩子与爽点、技术质量。严重度同写章流程：必须修、建议看、仅提示。去味按检测器提示处理；要完整三层去味走 `/story-deslop`。字数出了范围按 workflow-chapter「检测收口」处理，不在这里另判。

## 单章检查

### 章节结构
- [ ] 开头有钩子（不用空景或天气硬凑；慢热与过渡章从人物眼前的事切入）；第 1-3 章另按 opening-design「开篇落笔」查
- [ ] 中段有推进（快节奏题材要有具体事件；慢热题材状态变化即可）
- [ ] 局势有变化，或者本章把已经取得的关系、地位、生活实实在在演给读者享受；不能用没有新事件代替判断这一章的价值
- [ ] 结尾落在当前真实发生的结果、人物相处或继续值得期待的现场上（不是总结）

### 章节推进
- [ ] 推进章要有真实的目标 / 风险 / 信息 / 关系 / 资源 / 身份 / 立场变化；男频的风流、享乐、人物关系与生活群像章，即使没有新增状态，只要通过具体对话、动作、人物相处或已经取得的待遇持续交付目标体验，也可以成立。不能因为只是「日常」就自动认定为水，也不能拿「氛围」二字遮掩空写
- [ ] 不是水字数（删掉后读者会失去什么：实际结果、关系内容、人物魅力、当场享受、期待升价或兑现？如果都没有才压缩）
- [ ] 本章有任务卡点时，卡住是否真实引出人物选择、后果或读者期待？没有卡点的享受章不为过检临时制造障碍
- [ ] 推进强弱是否符合本书已建立的题材、兑现节奏与对标，而非套固定通用字数
- [ ] 兑现或高潮之后，是否给足已经赢得的权利、财富、关系和生活的使用与享受，而不是机械地立刻加新危机？篇幅按读者能否持续获得具体体验决定

### 信息传递
- [ ] 没有大段设定说明文
- [ ] 信息跟着人物行动、交往、选择或冲突走（通过真实场景传递设定），不依赖旁白灌输
- [ ] 设定量可控（一章不超 3 个新概念）

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 冲突场有阻碍（什么挡着）；过渡、盘点或温情日常场可不设硬阻碍
- [ ] 场景有实际作用：改变了人物或局面，或让读者享受到有内容的人物关系、风流得意和已得生活；纯重复的相处不算
- [ ] 心理段写的是新判断、误判或决定，不是反复翻译同一情绪
- [ ] 删掉某段后，事实、因果、声口、关系或情绪延续都没有损失，才删

### 章尾
- [ ] 钩子强度按细纲标的这章松还是紧核对：紧的章、推进章有危机/决定/发现/反转之一；松的章留阶段目标或情绪钩子即可
- [ ] 不是总结式结尾
- [ ] 拉住读者翻下一页

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 情绪词有落点（融进动作句、当对话提示语、结句后直接换事或接场内物件），不是接更多情绪
- [ ] 标题行外无章节/写作元信息（词表见 long-format）；承接前文用角色可感知的事件或相对时间

### 连载连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 主角行为符合人设，反派逼格匹配当前阶段
- [ ] 对照批准细纲核对新增物：闲话、即时反应和服务既有情节点的微连接不算；新关系、承诺、后续义务列入申报表交主会话处置，与细纲或既有事实冲突才算必须修

### 注水信号自查
出现以下情况时直接删压：
- 全章对话既没有新信息或立场变化，也没有人物声口、相处趣味、关系内容和具体情绪体验
- 同一种情绪只是换句形容词反复写，既没有新的行动、相处内容、人物表现，也没有不同层次的享受
- 大段场景描写既不推剧情，也不托人物与氛围
- 角色回忆往事，却没带出新视角或判断
- 流程细节或任务卡点删掉后不影响因果
