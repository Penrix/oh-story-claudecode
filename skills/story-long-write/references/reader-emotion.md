# 目标情绪与故事设计

> 定方向、设定、卷纲、细纲、写正文和审稿时使用。先知道要给读者什么感觉，再寻找能真正产生这种感觉的人物、关系和故事。不要只给情绪贴标签。

## 1. 三个问题

1. **情绪质地：想让读者获得什么感觉？** 如得意、风流、昂扬、豪迈、自由、温暖、偏爱、富贵享乐。先确定本书或当前剧情主要给什么感觉；其他感觉可以同时存在，但不要平均用力。
2. **情绪指向：为什么读者会有这种感觉？** 从选定的感觉出发，找需要怎样的能力、身份、关系、世界规则、社会评价、生活待遇和行动。不是列出女人、金钱、权力等物件就算完成；要说清它们为什么使读者产生目标感觉。
3. **情绪时间形状：这种感觉怎样一路发生？** 安排读者先感受什么、后来怎样变化、什么时候享受或兑现、什么还会继续。具体形状由目标感觉决定，不规定所有剧情必须先压抑再爆发。

**别把故事运动当成情绪。** “进武馆→成为亲传→武考得官身”是故事；“不甘→看见希望→得意→扬眉吐气→享受高位”是希望让读者体验的感觉。设计时两条线对照，不能只完成前一条。

## 2. 定方向与核心设定

1. 先用具体中文写出本书最想提供的两三种感觉，分清长期主要感觉与陪衬。作者已经指定时以作者的说法为准，不替换成题材的常见标签。
2. 每一种主要感觉都问“为什么能有这种感觉”。把答案落到具体人和世界：主角拥有什么凭借、想过什么生活、什么东西在这个世界值钱、谁有什么判断与行动、取得结果后能享受什么。
3. 用这些条件寻找终极目标、人物设定、世界规则和故事路线。现成作品只提供可利用的知识与经验，不替新书决定目标感觉或事件。

**情绪也负责创造世界和新故事。** 不先把世界当成定死的背景：从想交付的情绪和高价结果出发，设想需要出现哪些具体人物行为（争夺、合作、偏爱、评价、享受等），反推什么资源、资格、制度、金手指条件会自然促使这些行为发生（体验→行为→规则）；再让所选规则在本书运行，观察它如何改变人物利益、选择与新局面（规则→人物行动→Reader体验）。历史、现实、IP的既有人事物是可利用、改编或舍弃的素材。结果须包含本书自己的关系、行动和故事可能，不以替换作品专名交差。
4. 写进已有 `设定/题材定位.md` 和 `设定/全书梗概.md`，让下次会话仍然知道本书要提供什么感觉，以及为什么这些设定能产生它。

例：目标是“得意、风流、自由享乐”。需要的可能是男主有过人的本事，作品或事业不断取得成功，高价人物主动与他建立关系，他能实际享受成就与亲密生活。不要只把“获得一家公司”当作全部结果。

## 3. 卷纲和剧情单元

1. 根据当前主角身份、能力、关系和读者已知信息，确定本卷结束时要让读者得到什么新的体验。
2. 写出本卷的情绪变化过程，可以持续享受，也可以积累、回返、变奏、公开确认、阶段性兑现。不要套“压抑→加压→反转→爆发”的通用曲线。
3. 同时写出具体故事变化：人物取得什么、失去什么、认知或关系怎样改变，谁凭什么做成。情绪变化和故事事实各自说清。
4. 从当前处境到目标状态，选择真正需要的关键事件。不要为了凑情绪曲线凭空增加背叛、误会、危机或反派。
5. 参考对标书时，先找情绪质地和变化方式相近的模块，再借鉴节奏或戏剧做法；换到本书以后必须由本书人物作出符合现状的行动。

## 4. 细纲与正文

细纲中的 `目标情绪` 保留原字段名，写清“开始时读者是什么感觉→本章结束时是什么感觉”以及产生变化的具体原因。情绪保持不变时可写“持续温暖/得意/轻松”，说明本章靠什么维持，不强造反转。

**代入感也参与场景创造。** 从当前情绪反推人物具体怎样吃住、工作、交往、受到对待或享受已有权益，找到会影响其行为和关系的真实处境、物件与现场。不是先写一句「贫穷／风流／成功」再随机叠五感；场景材料要能让 Reader 身处「我与世界的关系」。

写正文前按顺序确认：

1. 读者到这一刻已经看过什么、正在期待或享受什么？
2. 这章主要要让读者获得哪种感觉？为什么本章人物和事件能产生它？
3. 男主与其他人物现在各自知道什么、想做什么？刚刚发生的事怎样改变他们下一步的行动？
4. 关键感觉是靠哪个可见行动、对话、关系变化、结果或停顿让读者真正感受到的？

写作时让人物从当前处境自然行动：已有状态→行动→别人反应→局面改变→新的行动。高层规划可以预定必要的结果，但不要用“需要关系升温”直接命令人物亲近；要通过真实相处让关系发生变化。

写完检查：读者实际上能感觉到什么？如果只剩流程、设定解说或数字奖励，返回有关场景补真实行动、反应、生活享受和人物关系。不是一律增加冲突或打脸。

## 5. 对标迁移与检查

**仅当确实使用对标时**，从对标 `剧情/情绪模块.md` 读取 `读者想看什么`、`情绪指向`（有则读）、`情绪链`，再读 `戏剧单元` 和 `可替换项`；没有对标也按本书情绪、世界和人物自行生成故事。

- 先对照目标感觉是否相近；同属一个题材、同叫“爽”都不够。
- 保留可迁移的感觉与变化，不照搬原人物身份、事件顺序和标志性桥段。
- 若原书靠“公开反证”制造得意，新书也可以靠“已经成功后的自在享受”制造得意，不必再安排一次公开打脸。
- 目标感觉已经兑现的部分要让读者享受；未兑现的部分才继续建立期待。不要把所有收益推迟到以后。

完成前自查：有没有说清想让读者获得什么感觉；为什么会产生；怎样沿本书阅读时间发生；真实人物和世界是否真的能演出来。答不上来就改有关设定或故事，不再堆情绪形容词。
